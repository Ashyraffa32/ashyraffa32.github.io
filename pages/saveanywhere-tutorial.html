Save Anywhere — Simple Omori Mod

About Page:

This page shows how to install the Save Anywhere Omori mod using OneLoader, what is compatible, and what to watch out for. Use the download button below when you are ready.

About This Mod:

This mod allows you to save your progress anywhere in the game Omori, without requiring the Mari's Picnic Basket...

1. Download OneLoader

OneLoader is the recommended mod loader for Omori on PC. Download the latest stable release from the official source and install it before adding this mod.

Important: this mod is built for the PC version of Omori, so use it with OneLoader on Steam or desktop installations only.

2. Install the mod with OneLoader

  1. Open OneLoader and make sure it is set up for your Omori installation.
  2. Place SaveAnywherev1.0.0.zip in the mods folder used by OneLoader, or use the OneLoader UI to add the mod file.
  3. Enable the mod in OneLoader and restart Omori after enabling it.
  4. Launch the game through OneLoader so the mod loads correctly.

If OneLoader asks whether to keep the package compressed, keep it as a zip file unless the loader specifically says to extract it.

Compatibility

  • Compatible with the PC/Steam version of Omori.
  • Highly Compatible with almost all mods.
  • Do not save during cutscenes or battles.
  • If you use other mods, install them one at a time and test the game between installs.

Error warnings

  • Always back up your save files before installing any mod.
  • If the game crashes, disable or remove the mod from OneLoader and restart the game.
  • Do not unzip the mod archive unless OneLoader specifically requires it.
  • If you see a compatibility error, verify your Omori install and try again with the latest OneLoader release.
